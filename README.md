# Практическая работа: Приложения Windows Forms (C#)

Проект представляет собой сборник из 8 мини-приложений, выполненных в рамках практической работы по C# (Windows Forms). Переключение между заданиями происходит через главное меню.

## Руководство пользователя

Данная программа является учебным проектом, демонстрирующим базовые возможности Windows Forms: работу с событиями, элементами управления, случайными числами и файлами.

Цель программы — предоставить удобный интерфейс для запуска и проверки каждого из 8 выполненных заданий.

**Интерфейс главного меню:**

1. Изначально открывается форма выбора задания.
2. Для перехода к нужному упражнению нажмите на соответствующую кнопку (от «задание 1» до «задание 8»).

## Как я делал

### 1. Создал главное меню
Создал проект **Приложение Windows Forms (.NET Framework)**. На главную форму (`Form1`) добавил 8 кнопок. В обработчиках их нажатия прописал создание экземпляров других форм и их открытие:
```csharp
Form2 form2 = new Form2();
form2.Show();
```

### 2. Реализация заданий (основные переменные и логика)

**Задание 1 (Угадай число):**
- Переменные: `int secretNumber; int attempts; Random rnd = new Random();`
- Логика: Генерация числа `rnd.Next(1, 101)`, сравнение введенного значения через `if-else`, инкремент счетчика попыток, вывод подсказок.

**Задание 2 (Случайный цвет):**
- Переменные: `Random random = new Random();`
- Логика: Генерация трех чисел `r, g, b` от 0 до 255. Смена цвета формы: `this.BackColor = Color.FromArgb(r, g, b);`

**Задание 3 (MessageBox):**
- Логика: Вызов `MessageBox.Show(textBox1.Text);` в обработчике кнопки.

**Задание 4 (Изменение кнопок):**
- Логика: В обработчике `Click` каждой кнопки: `((Button)sender).Text = textBox1.Text;`

**Задание 5 (Скрытые метки):**
- Логика: В обработчике события `Form_Load` всем меткам присваивается `label.Visible = false;`. Кнопки меняют это свойство на `true` для своих меток.

**Задание 6 (Блокировка TextBox):**
- Логика: Кнопки меняют свойство `textBox1.Enabled` на `true` или `false`.

**Задание 7 (Заметки):**
- Подключил библиотеку `using System.IO;`.
- Переменные: `SaveFileDialog`, `OpenFileDialog`.
- Логика: Использование `File.WriteAllText` для сохранения и `File.ReadAllText` для загрузки текста.

**Задание 8 (Калькулятор):**
- Переменные: `double num1, num2, result; char op;`
- Логика: Использование `try-catch` для отлова ошибок ввода, проверка деления на 0 (если делитель равен 0, выводится сообщение об ошибке).
